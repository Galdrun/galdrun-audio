# Galdrun branding

These logos and the name "Galdrun" are not covered by the repository's license;
see [TRADEMARK.md](../../TRADEMARK.md).

The SVGs here have the lettering converted to outlines (Montserrat, SemiBold or
Medium as given in each source), so they look the same on every device without
the font installed. The editable originals with live text are in
[`source/`](source/).

To change a logo, edit its file in `source/` and convert the text to outlines
again. Montserrat is under the SIL Open Font License, which allows its glyph
outlines in logos; the font itself is not part of this repository.

The settings pages of the client and the server show `01_pure_wordmark.svg`
inline (`shared/web/client-settings.html`, `server-gui/www/index.html`).
