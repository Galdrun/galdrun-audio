Core & playback

Which audio core the server uses, and how it plays.

Server core

Every core announcing itself in the last 6 s. The choice is kept by core id; the zones move with it.

Playback

How books go into a queue or a playlist, and what liked radio songs play as.

On: a book (two or more audiobook tracks) goes in as one item with its chapters. Off: as single tracks.

On: a song liked off the radio is looked for in the library first, then the streaming services, and plays as the track found. Off: not looked for; what was found stays.

Core audio

Timing used from the next start, pause, stop or seek.

A shorter start delay makes transport react sooner; too short and a room on a slow link gets the message too late and has to rejoin.
